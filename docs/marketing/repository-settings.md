## Public visibility checklist

Before changing the repository from private to public:

- [ ] Confirm `.env.local` is not in the repository.
- [ ] Confirm `.vercel` is not in the repository.
- [ ] Search the latest commit for API keys and deployment tokens.
- [ ] Confirm demo photos are safe and licensed for public display.
- [ ] Confirm the public demo uses mock mode and cannot spend the owner's API quota.
- [ ] Confirm the private live deployment remains protected by Vercel Authentication.
